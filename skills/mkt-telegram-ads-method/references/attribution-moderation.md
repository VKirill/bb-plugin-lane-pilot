# Telegram Ads: Сквозная атрибуция ботов/каналов, креативы 160 символов, модерация и антифрод

> **Целевой скилл**: `mkt-telegram-ads-method`
> **Назначение**: Практическое руководство по построению детерминированной атрибуции Telegram Ads (`?start=`, invite-ссылки, веб-UTM) в БД продукта, правилам написания креативов (160 символов) и тестирования `16:9` медиа, прохождению модерации без отклонений `Irrelevant destinations` и автоматическому отсечению ботных каналов.

## 1. Сквозная атрибуция Telegram Ads: запрет оценки по кликам кабинета

### 1.1. Почему клики в кабинете Telegram Ads не равны запускам бота (`Clicks != Starts`)
В объявлениях с изображением или видео тап пользователя по самой картинке (чтобы рассмотреть фото крупнее) засчитывается рекламным кабинетом как `Click` (`Joined / Started`), но **не запускает `/start` внутри бота**. На реальных производственных данных (кейс `PhotoAlive`) конверсия из кабинетного клика медиа-объявления в фактический `/start` в БД составляет от **`1–3%`** на широком холодном `Target Users` до **`15–40%`** на текстовых и узких канальных связках.

> **Аксиома измерения**: решения об отключении или масштабировании объявлений в Telegram Ads принимаются **исключительно по событиям в собственной БД продукта / CRM** (с обязательным исключением `user_id` владельцев, разработчиков и тестировщиков), а из кабинета забираются только `Views` (показы), `Spent` (расход в TON/EUR) и текущий `CPM`.

### 1.2. Стандарт именования `start`-меток для ботов и Mini Apps
Telegram ограничивает длину payload в глубокой ссылке `https://t.me/<bot>?start=<payload>` до **64 символов** (`A-Z`, `a-z`, `0-9`, `_`, `-`). Рекомендуемый детерминированный формат:

```text
src_<lang>-<cc>-<placement>-<creative>
```
Примеры:
- `src_ru-ru-u_f35-cr04_album` (`Target Users`, русский язык, РФ/СНГ, сегмент Ж35+, креатив №4 «альбом»);
- `src_en-us-ch_genealogy1-cr02_restore` (`Target Channels`, английский, США, пул генеалогии №1, креатив №2);
- `src_de-de-srch_geschenk-cr01` (`Search`, немецкий, Германия, ключ `geschenk`).

**Обязательные правила обработки `/start <payload>` на стороне бота**:
1. Сохранять **первый** непустой `source` при создании пользователя (`first_source`) и отдельно логировать повторные входы в таблицу `bot_sessions / ad_touches` (чтобы не перезатереть исходный платный источник при возврате пользователя по чистой ссылке).
2. Мгновенно переключать язык приветственного сообщения (`i18n`) по префиксу `<lang>` из `src_<lang>-...`, даже если системный `language_code` клиента Telegram отличается (критично для модерации!).
3. Выдавать в первом же экране ровно то обещание, которое было заявлено в 160 символах объявления, без многошаговых анкет и «подпишись ещё на 3 спонсорских канала».

### 1.3. Эталонный SQL-запрос сверки воронки Telegram-бота (`funnel.sql`)
Склейка снимка кабинета (`ad_snapshots`: `ad_id`, `start_param`, `views`, `clicks`, `spent_ton`, `cpm`) с продуктовой БД PostgreSQL:

```sql
WITH clean_users AS (
    SELECT u.id AS user_id,
           u.source AS start_param,
           u.created_at,
           u.last_seen_at,
           u.is_premium,
           u.photo_consent_at
    FROM users u
    WHERE u.source LIKE 'src_%'
      AND u.telegram_id NOT IN (100000001, 100000002) -- исключение тестовых ID команды
),
user_funnel AS (
    SELECT cu.start_param,
           COUNT(DISTINCT cu.user_id) AS bot_starts,
           COUNT(DISTINCT cu.user_id) FILTER (
               WHERE EXTRACT(EPOCH FROM (cu.last_seen_at - cu.created_at)) < 1
           ) AS zero_sec_bounces,
           COUNT(DISTINCT cu.user_id) FILTER (WHERE cu.is_premium IS TRUE) AS premium_users,
           COUNT(DISTINCT cu.user_id) FILTER (WHERE cu.photo_consent_at IS NOT NULL) AS consented_users,
           COUNT(DISTINCT g.user_id) AS generators,
           COUNT(DISTINCT i.user_id) AS invoice_openers,
           COUNT(DISTINCT p.user_id) AS payers,
           COALESCE(SUM(p.net_amount_eur), 0) AS revenue_eur
    FROM clean_users cu
    LEFT JOIN generations g
           ON g.user_id = cu.user_id AND g.status = 'done'
    LEFT JOIN invoices i
           ON i.user_id = cu.user_id
    LEFT JOIN payments p
           ON p.user_id = cu.user_id AND p.status = 'succeeded' AND p.refunded_at IS NULL
    GROUP BY cu.start_param
)
SELECT a.ad_id,
       a.status,
       a.cpm,
       a.views,
       a.clicks AS cab_clicks,
       a.spent_ton,
       COALESCE(f.bot_starts, 0) AS starts,
       COALESCE(f.consented_users, 0) AS consents,
       COALESCE(f.generators, 0) AS generators,
       COALESCE(f.invoice_openers, 0) AS checkouts,
       COALESCE(f.payers, 0) AS payers,
       ROUND(a.spent_ton / NULLIF(f.generators, 0), 3) AS cost_per_gen_ton,
       ROUND(a.spent_ton / NULLIF(f.payers, 0), 3) AS cps_ton,
       COALESCE(f.revenue_eur, 0) AS rev_eur
FROM latest_ad_snapshots a
LEFT JOIN user_funnel f USING (start_param)
ORDER BY a.spent_ton DESC;
```

### 1.4. Атрибуция при продвижении Telegram-канала и внешнего сайта
- **Продвижение канала**: создавать в настройках канала отдельную **пригласительную ссылку (`Invite Link`)** под каждое объявление/пул (без ручного одобрения заявок, если не тестируется закрытый клуб) и забирать по Bot API (`chat_member` webhook) не только факт подписки, но и **удержание через 7 дней (`Retained Subscriber 7d`)**, отсеивая отписавшихся в первые 24 часа.
- **Продвижение сайта**: стандартная разметка `utm_source=telegram_ads&utm_medium=cpm&utm_campaign=<pool>&utm_content=<ad_id>` + проверка корректной работы мобильного встроенного браузера Telegram (`In-App WebView`), автозаполнения телефона и сохранения cookie/ClientID до отправки формы.

## 2. Формулы креативов (160 символов) и тестирование медиа (`Text` vs `16:9`)

### 2.1. Жёсткая анатомия текста до 160 символов
Лимит текста объявления Telegram Ads — ровно **160 символов** (включая пробелы и знаки препинания), заголовок формируется автоматически из названия рекламируемого канала/бота, а кнопка содержит короткий системный CTA (`Start Bot`, `View Channel`, `Open Website`).

В 160 символах нет места вводным словам — работают 4 проверенные конструкции:
1. **Ситуация / Триггер + Конкретный результат + Снятие трения**:
   `Старое семейное фото выцвело в альбоме? Оживите улыбку близких на видео за 60 секунд прямо в Telegram — первый пример бесплатно.`
2. **Сегментный фильтр («Для кого») + Цифра выгоды + Следующий шаг**:
   `Селлерам на WB и Ozon: расчёт реальной чистой прибыли с учётом логистики и штрафов за 2 минуты. Заберите таблицу в боте.`
3. **Контраст со старым способом + Артефакт / Лид-магнит**:
   `Вместо 3 часов ручной сводки отчётов Директа — готовый дашборд в один клик. Откройте демо-шаблон в канале.`
4. **Прямой ответ на поисковый интент (для `Search`)**:
   `Ищете подарок родителям на годовщину? Соберите трогательный видеоролик из архивных снимков в боте за 5 минут.`

**Трёхточечный копирайтинг-гейт для 160 символов (`Sugarman + Ogilvy + Bly`)**:
- **Sugarman (`Curiosity Hook` + `Slippery Slide`)**: первые `45–60` символов цепляют конкретным узнаваемым симптомом или контрастом со старым способом без кликбейта и запрещённых модерацией повелительных окриков, втягивая взгляд во второе предложение.
- **Ogilvy (`Factual Specificity`)**: минимум `1–2` проверяемые цифры внутри 160 знаков (время получения результата, точный сегмент, бесплатный тестовый пример) вместо пустых прилагательных («лучший», «уникальный»).
- **Bly (`Feature -> Benefit`)**: называть не механику кода («ИИ-ассистент с парсером API»), а конечную выгоду в руках пользователя («расчёт реальной чистой маржи с учётом логистики за 2 минуты»).

### 2.2. Когда оправдана картинка / видео (`16:9`), а когда побеждает чистый текст
Поскольку добавление картинки повышает минимальный CPM на **`+50%..+80%`** (`💎0.10 -> 💎0.17/0.18`) и добавляет случайные тапы по изображению:
- **Визуальный демонстрационный продукт** (оживление фото, дизайн интерьера, товар лицом, до/после без нарушения правил шок-контента): `16:9` изображение повышает пробитие баннерной слепоты в 2–4 раза, но требует оценки строго по `Cost per Activation` (`spent / generators`), а не по `CPC`.
- **Экспертный канал, B2B-услуга, финансы, аналитика**: чистый текст на ставке `💎0.10–0.14` зачастую даёт в `1.5–2×` более дешёвого подписчика или квалифицированный старт бота, так как кликает только прочитавший суть оффера пользователь.
- **Правило теста**: на старте любой новой вертикали запускается парный сплит на одном и том же эталонном пуле: `Объявление А (чистый текст, минимальный CPM)` против `Объявления Б (тот же текст + 16:9 визуал, CPM +50–80%)`. Победитель определяется по стоимости целевого действия глубины воронки (`Cost per Lead / Generator`).

## 3. Правила модерации Telegram Ads и защита от отклонений

Модерация Telegram Ads проверяет одновременно **текст объявления, визуал, аватар/описание бота или канала и фактическое поведение посадочной после перехода**.

| Причина отклонения (`Declined`) | Конкретный триггер ошибки | Инженерное правило предотвращения |
|---|---|---|
| **`Irrelevant destinations` / Language Mismatch** | Объявление на немецком или испанском ведёт в бота, который встречает пользователя русским или английским текстом; либо обещан конкретный гайд, а открывается общая лента канала без закрепа | Бот обязан парсить `src_<lang>-...` на команде `/start` и отдавать локализованное приветствие на языке объявления с первой секунды; для канала — вести прямую ссылку на конкретный пост с обещанным материалом `t.me/channel/123` |
| **Повелительное давление и агрессивный тон** | Прямые приказы в повелительном наклонении с восклицаниями (`Жми срочно!`, `Купи прямо сейчас!`, `Успей забрать!`), тыканье («Ты теряешь деньги!») | Спокойный информативный тон на «вы» или безличные конструкции («Попробуйте в боте», «Подробный разбор в канале») |
| **Запрещённая типографика** | `КАПСЛОК` (кроме общепринятых аббревиатур `CRM`, `AI`, `B2B`), обилие эмодзи (`> 1` или списки из смайлов), переносы строк / буллиты в тексте объявления, неграмотная пунктуация | Одна связная строка чистого текста без переносов строк, без капса, `0` (максимум `1` нейтральный) эмодзи |
| **Превосходная степень и гарантии дохода** | «Самый лучший сервис №1», «Гарантированный заработок 300%», обещания исцеления, финансовые обещания без лицензии | Только проверяемые факты о механике продукта без не доказуемых сравнений и обещаний обогащения |
| **Шок-контент / эксплуатация горя в медиа** | Спекуляция на смерти, болезнях, трауре, пугающие «до/после» | Тёплая позитивная подача («сохраните семейную память», «оживите архивный снимок с праздника») |

## 4. Детекция ботного фрода и решающие правила остановки ячеек

В сети `Target Channels` часть публичных каналов системно откручивает показы и клики фермами скриптов, чтобы имитировать высокую активность рекламного места.

### 4.1. Сигнатура ботного канала / скликивания (на примере инцидента `cell 216 ch3`)
Немедленно переводить ячейку в `On Hold` с последующим выводом бюджета (`decrAdBudget` через 10 минут), если выполняется **любой** из маркеров аномалии при `>= 30` кликах или `>= 20` запусках `/start`:
1. **Аномальный CTR при мёртвой воронке**: `CTR > 10–15%` (в реальном ботном инциденте — `39.8%`, `115` кликов на `289` показов) при **`0`** целевых действий второго шага (`consented_users == 0`, `generators == 0`).
2. **Мгновенный отвал нулевой секунды (`Zero-Second Bounce`)**: у `>= 80%` пришедших пользователей в БД выполняется `last_seen_at - created_at < 1 sec` (скрипт шлёт команду `/start` и никогда не нажимает ни одну inline-кнопку).
3. **Нулевая доля Telegram Premium на платящем гео**: при `>= 30` стартах доля `is_premium == true` равна `0%` (тогда как на живом трафике РФ/Tier-1 доля Premium составляет `8–25%`), а имена аккаунтов образуют однотипные сгенерированные серии с одинаковым интервалом прихода.

### 4.2. Матрица стоп-лоссов и масштабирования (Decision Gate)
Пусть плановый потолок стоимости целевой активации (лида / первой генерации) равен $C_{\max}$ (например, `💎0.33`):
- **`STOP (Hard Kill)`**: расход ячейки достиг `2 × C_max` (`0` активаций) либо `>= 3 × C_max` при фактической цене активации `> 1.8 × C_max`, либо сработал детектор ботного трафика $\Rightarrow$ `status = "on_hold"` + вывод остатка через `10` минут.
- **`HOLD / STEP CPM`**: расход `< 1 × C_max`, показов `< 300` за 3 дневных часа $\Rightarrow$ поднять CPM на 1 ступень (`+30–40%`), не меняя текст.
- **`PROMOTE TO VOLUME`**: скрининговая ячейка (`💎1.00`) дала `>= 3` валидных активаций по цене `<= C_max` с живой глубиной (`invoice_opened > 0`, нормальная доля `is_premium`) $\Rightarrow$ пополнить ячейку до объёмного теста (`💎5.00–10.00`) для статистически значимой проверки конверсии в оплату (`CPS`) и параллельно раскатать креатив-победитель на соседние релевантные пулы каналов.
