# Enabled settings (generated)

TL;DR: generated by `scripts/generate-enabled-settings.ts` from the typed settings registry — not written by hand. Column «`*`» is the hub's global row
(`docs/enabled-settings.snapshot.json`, refreshed with `--db <path to the hub data.db>`; fetched never — rerun on the hub). A stage setting that is unset is recorded `skipped` with reason `disabled_by_project_setting`.

## How it works

Every stage and loop reads its switch through `loadProjectSettings` (project rows over the `*` rows). The defaults below come from each room's `defineSetting` definition; where the code holds a different fallback, the constants table states it. `quality_mode` of a task or project overrides the critique
switches: `quick` disables both critiques, `full` enables them (`src/rooms/critique/quality-mode.ts:16-24`).
