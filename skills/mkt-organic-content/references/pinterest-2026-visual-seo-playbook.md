# Pinterest 2026: визуальное SEO длинного хвоста

> **Целевой скилл**: `mkt-organic-content`
> **Источники**: 22 транскрипта курса Марии Богдановой «Комбо-пакет по Pinterest 2026» (85 611 слов): «Рывок» (вводный ролик и 5 дней: профиль → доски → контент → фишки контента → анализ и ошибки), «Спринт» (15 дней, 30 идей пинов) и мини-урок о стиле визуала. Разделы 1–7 — инженерная модель платформы. Раздел 8 сверяет её со сказанным в курсе, и там, где они расходятся, правит курс.
> **Скрипт**: `audit_organic_pack.py`, канал `pinterest_pin` и пакетные проверки `pk_link_throttle`, `pk_utm_campaign`.

## 1. Модель платформы

| Свойство | Следствие для работы |
|---|---|
| Поиск по картинкам, а не лента подписок | Ключевые слова в заголовке, описании, доске и профиле важнее числа подписчиков |
| Пин живёт месяцами | Оценка по накопленному трафику за 30–90 дней, а не за сутки |
| Новое = новое изображение | На один URL делают несколько разных изображений и разносят их по дням |

## 2. Профиль и доски (порядок «Рывка»)

Профиль:
- бизнес-аккаунт и подтверждённый сайт (без них нет аналитики переходов);
- в отображаемом имени есть главный ключ ниши;
- в описании 2–3 ключевые фразы естественным языком и выгода;
- на старте 10–20 досок, каждая — один кластер запросов.

Доска:

| Поле | Правило |
|---|---|
| Название | головной ключ кластера, ≤ 50 знаков, без абстрактных названий |
| Описание | 2–4 длинных хвоста в предложениях |
| Наполнение | ≥ 10–15 пинов до продвижения |
| Соответствие | ключи пина пересекаются с ключами доски (`pin_board_match`, error) |

## 3. Карта ключей

```text
запрос (подсказки поиска, тренды) → кластер → доска
  → пин: заголовок (ключ в первых 40 знаках) · описание (≥ 2 ключа, ≤ 3 хештега) · надпись (≤ 8 слов) · ссылка (посадочная кластера + UTM)
```

Покрытие кластера = доля запросов кластера, на которые есть хотя бы один пин с ключом в заголовке. Цель — ≥ 0,6 за 30 дней на 3–5 главных кластерах. Глубина важнее ширины.

## 4. Визуальная иерархия пина

| Проверка | Правило | Severity |
|---|---|---|
| `pin_aspect_2x3` | высота / ширина 1,45–1,55 (1000 × 1500), ширина ≥ 1000; выше 2,1 — обрезка в ленте | warn / error |
| `pin_overlay_hook` | надпись есть, ≤ 8 слов; > 12 слов — нечитаемо | warn / error |
| `pin_title_len` | 20–100 знаков | warn / error |
| `pin_title_keyword` | главный ключ в первых 40 знаках | error |
| `pin_desc_len` | 100–500 знаков | warn / error |
| `pin_desc_keywords` | ≥ 2 целевых ключа, ≤ 3 хештега | warn |

Порядок чтения кадра: фокусный объект с результатом → надпись с выгодой в верхней трети → мелкий знак домена внизу. Палитра одна на всю доску: в поиске узнаваемость работает так же, как обложка в ленте.

## 5. Каденция: настройка и ежедневный режим

| Режим | Задача | Темп | Выход |
|---|---|---|---|
| Рывок (настройка) | профиль, доски, первые пины, разбор | 5 дней, по одному слою в день | доски наполнены ≥ 10 пинами, видна аналитика |
| Спринт (каденция) | свежие пины по кластерам | новый аккаунт: 1–3 в день 2 недели, затем 5–10 | 15 дней без пропуска, есть сохранения и переходы |

Разгон объёма: не чаще раза в неделю и не больше чем вдвое за шаг. Скачок с нуля до десятков пинов в день выглядит как автоматизация.

## 6. Исходящие ссылки без антиспам-ограничений

| Проверка | Правило | Severity |
|---|---|---|
| `pin_outbound_utm` | `https`; без сокращателей; `utm_source=pinterest`, `utm_medium`, `utm_campaign` | error |
| `pk_link_throttle` | один URL ≤ N пинов в день (по умолчанию 5, для нового аккаунта 1–2) | warn |
| `pk_utm_campaign` | одна `utm_campaign` на пакет | warn |

Ещё три правила: у каждого кластера своя посадочная; домен совпадает с подтверждённым сайтом; первый экран посадочной повторяет обещание надписи пина.

## 7. Анализ результатов

```text
SR   = сохранения / показы
OCTR = переходы / показы
Lead = лиды с utm_source=pinterest / переходы
```

| Картина | Диагноз | Действие |
|---|---|---|
| Мало показов | ключи не совпадают с запросами или доска не та | переписать заголовок и описание под подсказки, проверить доску |
| Показы есть, SR низкий | визуал не цепляет | новая надпись или новый фокус, тот же URL на новом изображении |
| SR высокий, OCTR низкий | пин самодостаточен | надпись обещает то, чего нет на картинке: расчёт, шаблон, полный список |
| OCTR высокий, лидов нет | посадочная не держит обещание | сверить первый экран с надписью |
| Показы упали после роста объёма | похоже на антиспам | вернуться на прошлую ступень, разнести одинаковые URL по дням |

## 8. Ревизия 2: что сказано в курсе [T]

Транскрипты «Рывка» (6), «Спринта» (15) и мини-урока о стиле сверены по таймкоду. Расшифровка местами шумная, поэтому числа здесь — порядок величины из практики спикера. Подробности — в мастер-досье `organic-content-2026`, часть 2.

**Модель.** Pinterest здесь — визуальный поисковик. Пин ранжируют по ключам в названии, описании, доске и профиле и по тексту на картинке, который читает визуальный поиск. Клик и сохранение ускоряют пин: сохранённый пин видят подписчики того, кто его сохранил. Результат приходит через 3–4 месяца, первые 2 месяца низкие переходы нормальны. Стратегию раньше этого срока не меняют.

**Лимиты курса и линтер.**

| Поле | Курс | Линтер по умолчанию |
|---|---|---|
| Название | До 100 знаков, целиком ключами | `pin_title_len` 20–100 |
| Описание | До 800 знаков: суть → призыв по ссылке → блок ключей | `pin_desc_len` 100–500; курсовой лимит задаётся `"thresholds": {"pin_desc_max": 800}` |
| Ключи | До 20; для SEO-пина 15–20 ключей и 5–7 хэштегов | `pin_desc_keywords` |
| Формат | 1000 × 1500 (2:3), 3:4 при малом тексте, 9:16 при подробных пунктах | `pin_aspect_2x3` |
| Текст на картинке | 3–5 пунктов, чек-лист 5–7 | `pin_overlay_hook` ≤ 12 слов в надписи-крючке |

Опубликованные пины не правят: лимит около 10 правок за раз, частые правки выглядят как спам. Свои пины не удаляют даже с нулём просмотров. Новым считается тот же материал с новым названием и описанием, а повтор старого пина делают с разрывом в несколько месяцев.

**Каденция — объём решает.** Один пин в день даёт меньше 10 тыс. просмотров в месяц. Рабочий объём — от 20 пинов в день, на запуске 30–50 (утро и вечер). «Рывок» ставит ориентир 30 пинов в день 7 дней подряд. Пропорция тем — 80 % профильного контента и не больше 20 % виральных посторонних картинок. Теневой бан вызывают сотни пинов в сочетании с массовыми лайками, комментариями и приглашениями в групповые доски, а не сам объём пинов. Это поправка к прежней осторожной модели «1–3 в день».

**Ссылки.** Сокращённые ссылки Pinterest блокирует. Массово менять ссылки в старых пинах нельзя, поэтому надёжный вариант — фраза «ссылка в шапке профиля» и смена ссылки только в профиле. `pin_outbound_utm` остаётся гейтом: курс атрибуцию не ведёт, но переход ещё не подписка. Если 100 переходов дают 0 подписок, чинить надо посадочную. Pinterest заманивает, Telegram рассказывает, а заявки собирает бот, не Google Forms.

**Аналитика.** Ориентир переходов — OCTR около 0,1 % показов (у кого-то до 1 %). Хороший график показов ровный или плавно растущий; график «импульсами» значит, что тема меняется каждый день. Через 1–1,5 месяца открывают «Популярные пины», сортируют по каждой метрике и повторяют победителей вариантами через 5–7 дней. Окна теста: ключи 10–14 дней, лид-магнит в шапке — минимум две недели. Около 2 просмотров на пин за две недели на старом захламлённом аккаунте — сигнал завести новый.

**Рынок РФ.** При стране аккаунта «Россия» рилсы Instagram не подтягиваются, только карусели; таргет не работает; Trends и аналитика ориентированы на США.
