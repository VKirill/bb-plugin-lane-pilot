# Brief, draft and quality-control gates

> [!NOTE] Provenance
> Independently worded engineering synthesis. Field names and acceptance contracts below are integration conventions, not verbatim source templates. Model outputs remain hypotheses until supported by observations.

## Brief gate

Require a verified user task, audience segment, locale, journey stage, chosen page role, source packet, trust requirements, existing URL decision and business outcome. Format Fit selects how the answer should work; it does not automatically imply a long article. Commercial Intent connects a task to an actual service or product rather than adding aggressive wording.

## Production gates

1. **Input readiness:** validate project facts and document missing data. If the business cannot serve the locale or support the page promise, return that dependency before drafting.
2. **Brief readiness:** connect each required block to a user decision and evidence. State what the page must not claim, which facts change over time and who verifies sensitive statements.
3. **Draft fidelity:** verify every material claim against the packet. Preserve limitations and source status; do not convert an upstream hypothesis into an asserted fact.
4. **Functional quality:** check task completion, useful original value, natural terminology, appropriate format, real link destinations and visible/structured-data agreement. Style polishing happens after these checks.
5. **Release proposal:** return accepted content, unresolved issues, owner/reviewer decisions and a measurable follow-up plan. Passing a prompt critic does not publish the page or demonstrate search performance.

## Synthesized QC artifact

For each defect, save location, violated requirement, evidence, severity, fix owner and acceptance check. Hard failures include unsupported facts, invented first-hand experience, fake sources, non-existent URLs, contradictory offers and unreviewed consequential claims. Soft issues such as tone should not hide factual failure.

## Evaluation limits

Use a fixed set of real examples and known difficult cases when revising templates. Preserve prompt, model and source versions. An LLM judge can screen outputs but needs human calibration; apparent consistency may simply repeat the same error. Decisions to scale follow measured outcomes and actual delivery capability, not output length or a round quality score.
