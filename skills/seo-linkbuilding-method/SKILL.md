# SEO link-building method

Order of operations: acceptors first, donors second. A link to an isolated, cannibalizing or unfinished page amplifies the defect. Source: «SEO Монстр 2027», ch6 pp. 471–560, plus the Link Target Readiness Analyzer flow (pp. 723, 729–731).

## When

- Setting up link-building management for priority URLs, before any donor search
- Monthly triage of 10–20 candidate URLs for link acquisition
- Planning a link sprint for a prepared cluster or commercial section
- Auditing link-profile naturalness/risk, inheriting a project, a sudden link spike
- Contracting a link vendor, broker, expired domain or network placement
- An agency proposes toxic-link cleanup, or a link manual action appears in GSC
